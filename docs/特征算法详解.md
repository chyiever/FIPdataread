# FIPread 短时特征算法详解

本文档结合 `src/processing.py` 中的特征计算函数，逐一说明 Plot 2 中每个短时特征：

- **计算公式**（数学表达式）
- **中文含义**（特征在说什么）
- **物理意义**（为什么有意义）
- **函数定义与实现代码**（完整源码，可直接阅读）

所有特征均基于 **CH1 相位数据**（时域信号，单位 **rad**）计算。

---

## 0. 公共机制

### 0.1 滑窗

设采样率为 `fs`，窗长参数为 `window_seconds`，步长参数为 `step`：

```
window_samples = max(2, round(window_seconds × fs))      # 窗长（样本数）
hop_samples    = max(1, round(window_samples × step))    # 步长（样本数）
```

- 窗起点依次为 `0, hop, 2·hop, ...`，直到最后一个完整窗 `signal.size − window_samples`。
- 每个窗的输出 X 坐标 = 窗中心样本索引：`start + window_samples / 2`。
- 返回值约定：`(centers, values)`，两者等长，`centers` 为窗中心（样本索引），`values` 为对应特征值。

### 0.2 幅度门控（Amplitude Gate）

`compute_short_time_energy_ratio` 与 `compute_short_time_band_energy` 支持门控参数 `gate_values`（默认取 `values` 本身；在 FIPread 中传入当前显示波形 `_current_display_values`，因此特征曲线跟随显示滤波设置）：

```
若 max(|gate_segment|) < amplitude_threshold：该窗特征值 = 0.0
```

即：窗内显示波形峰值低于阈值的窗被静音（输出 0）。

### 0.3 输出约定

- 失败或参数非法时返回两个空数组 `(np.array([]), np.array([]))`。
- 一级特征（Ratio / Energy / PSD sum）输入为**原始一维信号**；二级特征（Energy Energy / max-num）输入为**一级特征曲线** `(feature_centers, feature_values)`。

## 1. ST Energy Ratio（短时两频带能量密度比）

### 中文含义

在滑动窗内，比较两个指定频带（Band 1 与 Band 2）的**功率谱密度**比值，以 dB 表示。

### 物理意义

衡量频带 1 相对频带 2 的**能量集中度**。若某事件/信号主要落在 Band 1，该比值升高；用于刻画谱形状的时变特征。频带取功率谱密度（除以带宽）可消除带宽不同带来的偏差。

### 计算公式

预处理：4 阶 Butterworth **100 Hz 高通** 零相位滤波（`sosfiltfilt`）。

对每个窗：

1. 窗内信号乘以 **Hann 窗**，作 FFT：`power = |FFT|²`。
2. 频率轴 `f_k = k·fs / window_samples`（`rfftfreq`），频带掩码 `low ≤ f_k ≤ high`。
3. 频带能量密度：

$$
E_1 = \frac{\sum_{k \in \text{Band 1}} P_k}{\text{Band 1 High} - \text{Band 1 Low}},\qquad
E_2 = \frac{\sum_{k \in \text{Band 2}} P_k}{\text{Band 2 High} - \text{Band 2 Low}}
$$

4. 输出：

$$
\text{ratio[dB]} = 10 \cdot \log_{10}\!\left(\frac{E_1}{E_2}\right)
$$

取对数前加下限 `numpy.finfo(float).tiny`，避免 `log10(0)`。

### 函数定义与实现代码

```python
def compute_short_time_energy_ratio(
    values: np.ndarray,                # 输入：一维信号数组（rad），长度 N
    sample_rate: float,                # 采样率（Hz）
    *,
    numerator_low_hz: float,           # Band 1 下限（Hz）
    numerator_high_hz: float,          # Band 1 上限（Hz）
    denominator_low_hz: float,         # Band 2 下限（Hz）
    denominator_high_hz: float,        # Band 2 上限（Hz）
    window_seconds: float,             # 窗宽（s）
    hop_ratio: float,                  # 步长 = window_samples × hop_ratio
    amplitude_threshold: float,        # 幅度门控阈值
    gate_values: Optional[np.ndarray] = None,  # 门控信号（None 时用 values）
) -> tuple[np.ndarray, np.ndarray]:    # 输出：(窗中心样本索引, 比值[dB])
    signal = np.asarray(values, dtype=np.float64)
    gate_signal = signal if gate_values is None else np.asarray(gate_values, dtype=np.float64)

    # ===================== 1. 输入校验 =====================
    if signal.size == 0 or sample_rate <= 0.0:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)
    if gate_signal.size != signal.size:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    # ===================== 2. 滑窗网格生成 =====================
    # 窗长与步长（样本数），窗起点按固定步长铺满整个信号
    window_samples = max(2, int(round(window_seconds * sample_rate)))
    if window_samples > signal.size:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    hop_samples = max(1, int(round(window_samples * hop_ratio)))
    starts = np.arange(0, signal.size - window_samples + 1, hop_samples, dtype=np.int64)
    if starts.size == 0:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    # ===================== 3. 频带掩码与预计算 =====================
    # 单边谱频率轴，频带掩码：low <= f <= high
    freqs = np.fft.rfftfreq(window_samples, d=1.0 / sample_rate)
    numerator_mask = (freqs >= numerator_low_hz) & (freqs <= numerator_high_hz)
    denominator_mask = (freqs >= denominator_low_hz) & (freqs <= denominator_high_hz)
    if not np.any(numerator_mask) or not np.any(denominator_mask):
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    # 带宽用于把带内功率和折算成能量密度（功率/Hz）
    numerator_bandwidth = max(numerator_high_hz - numerator_low_hz, np.finfo(np.float64).eps)
    denominator_bandwidth = max(denominator_high_hz - denominator_low_hz, np.finfo(np.float64).eps)
    # Hann 窗用于抑制频谱泄漏；floor 避免 log10(0)
    window = get_window('hann', window_samples, fftbins=True).astype(np.float64, copy=False)
    floor = np.finfo(np.float64).tiny
    centers = np.empty(starts.size, dtype=np.float64)
    ratios_db = np.empty(starts.size, dtype=np.float64)

    # ===================== 4. 逐窗计算能量密度比 =====================
    for index, start in enumerate(starts):
        stop = int(start + window_samples)
        segment = signal[int(start):stop]
        gate_segment = gate_signal[int(start):stop]
        centers[index] = start + (window_samples * 0.5)  # 窗中心样本索引
        if segment.size < window_samples or gate_segment.size < window_samples:
            ratios_db[index] = 0.0
            continue
        # --- 幅度门控：窗内显示波形峰值过低则输出 0 ---
        if float(np.max(np.abs(gate_segment))) < amplitude_threshold:
            ratios_db[index] = 0.0
            continue

        # --- 加窗 FFT，求功率谱 ---
        spectrum = np.fft.rfft(segment * window)
        power = np.abs(spectrum) ** 2
        # --- 两频带能量密度 ---
        numerator_energy = float(np.sum(power[numerator_mask]))
        denominator_energy = float(np.sum(power[denominator_mask]))
        numerator_density = numerator_energy / numerator_bandwidth
        denominator_density = denominator_energy / denominator_bandwidth
        # --- 比值取对数(dB) ---
        ratio = numerator_density / max(denominator_density, floor)
        ratios_db[index] = 10.0 * np.log10(max(ratio, floor))

    # ===================== 5. 返回结果 =====================
    return centers, ratios_db
```

## 2. ST Energy（短时频带能量）

### 中文含义

在滑动窗内，计算经指定频带带通滤波后的**时域信号的平方和**（时域能量），线性坐标。

### 物理意义

指定频带内的信号能量随时间的变化。因为先做带通滤波，只有该频带内的能量被计入，可用来刻画某一频带能量脉冲（如撞击、裂纹、放电事件）出现的时刻与强度。

### 计算公式

预处理：4 阶 Butterworth **带通** `[Band Low, Band High]` 零相位滤波（`sosfiltfilt`）；若 `Band Low = 0`，退化为 `Band High` 处的低通。

对每个窗：

$$
\text{energy} = \sum_{n \in \text{窗}} x_{\text{filtered}}[n]^2
$$

线性输出（非 dB）。

### 函数定义与实现代码

```python
def compute_short_time_band_energy(
    values: np.ndarray,                # 输入：一维信号数组（rad），长度 N
    sample_rate: float,                # 采样率（Hz）
    *,
    band_low_hz: float,                # 带通下限（Hz）
    band_high_hz: float,               # 带通上限（Hz）
    window_seconds: float,             # 窗宽（s）
    hop_ratio: float,                  # 步长 = window_samples × hop_ratio
    amplitude_threshold: float,        # 幅度门控阈值
    gate_values: Optional[np.ndarray] = None,  # 门控信号（None 时用 values）
) -> tuple[np.ndarray, np.ndarray]:    # 输出：(窗中心样本索引, 能量值)
    signal = np.asarray(values, dtype=np.float64)
    gate_signal = signal if gate_values is None else np.asarray(gate_values, dtype=np.float64)

    # ===================== 1. 输入与频带校验 =====================
    if signal.size == 0 or sample_rate <= 0.0:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)
    if gate_signal.size != signal.size:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    nyquist = sample_rate / 2.0
    if band_low_hz < 0.0 or band_high_hz <= 0.0 or band_low_hz >= band_high_hz:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)
    if band_high_hz >= nyquist:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    # ===================== 2. 频带滤波预处理 =====================
    # 4 阶 Butterworth 带通，sosfiltfilt 零相位；Band Low=0 时退化为低通
    if band_low_hz > 0.0:
        sos = butter(
            N=4,
            Wn=[band_low_hz / nyquist, band_high_hz / nyquist],
            btype="bandpass",
            output="sos",
        )
    else:
        sos = butter(
            N=4,
            Wn=band_high_hz / nyquist,
            btype="lowpass",
            output="sos",
        )
    filtered = sosfiltfilt(sos, signal)

    # ===================== 3. 滑窗网格生成 =====================
    window_samples = max(2, int(round(window_seconds * sample_rate)))
    if window_samples > signal.size:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    hop_samples = max(1, int(round(window_samples * hop_ratio)))
    starts = np.arange(0, signal.size - window_samples + 1, hop_samples, dtype=np.int64)
    if starts.size == 0:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    centers = np.empty(starts.size, dtype=np.float64)
    energies = np.empty(starts.size, dtype=np.float64)

    # ===================== 4. 逐窗计算时域能量 =====================
    for index, start in enumerate(starts):
        stop = int(start + window_samples)
        segment = filtered[int(start):stop]
        gate_segment = gate_signal[int(start):stop]
        centers[index] = start + (window_samples * 0.5)  # 窗中心样本索引
        if segment.size < window_samples or gate_segment.size < window_samples:
            energies[index] = 0.0
            continue
        # --- 幅度门控：窗内显示波形峰值过低则输出 0 ---
        if float(np.max(np.abs(gate_segment))) < amplitude_threshold:
            energies[index] = 0.0
            continue
        # --- 频带内时域能量：Σ x[n]² ---
        energies[index] = float(np.sum(segment ** 2))

    # ===================== 5. 返回结果 =====================
    return centers, energies
```

## 3. ST Energy Energy（ST Energy 的能量）

### 中文含义

对 `ST Energy` 特征曲线再做一次滑动窗能量求和，即“能量的能量”。

### 物理意义

`ST Energy` 用很短的窗（默认 0.1 ms）捕捉高频能量的瞬时起伏，波动剧烈。在较宽窗（默认 20 ms）内对其平方求和，相当于对该频带能量脉冲做**包络能量累积**，平滑瞬时噪声、突出能量事件簇，且对大值（平方）更敏感。

### 计算公式

**阶段 1**：同 `ST Energy`，输出曲线 `(y[i], t[i])`：

$$
y[i] = \sum_{n \in \text{窗}_i} x_{\text{filtered}}[n]^2
$$

**阶段 2**：以窗宽 `window_seconds`、步长 `hop_ratio × window_samples` 滑动：

$$
\text{out}[j] = \sum_{i:\, t[i] \in \text{窗}_j} y[i]^2
$$

X 坐标为二级窗中心时间。线性输出。

### 函数定义与实现代码

```python
def compute_short_time_energy_sum(
    feature_centers: np.ndarray,       # 阶段1 窗中心（样本索引）
    feature_values: np.ndarray,        # 阶段1 特征值
    *,
    window_seconds: float,             # 二级窗宽（s）
    hop_ratio: float,                  # 二级步长 = window_samples × hop_ratio
    sample_rate: float,                # 采样率（Hz），用于把秒换算成样本
) -> tuple[np.ndarray, np.ndarray]:    # 输出：(二级窗中心, 二级平方和)
    centers = np.asarray(feature_centers, dtype=np.float64)
    values = np.asarray(feature_values, dtype=np.float64)

    # ===================== 1. 输入校验 =====================
    if centers.size == 0 or values.size != centers.size or sample_rate <= 0.0:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)
    if window_seconds <= 0.0 or hop_ratio <= 0.0 or hop_ratio > 1.0:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    # ===================== 2. 二级滑窗网格生成 =====================
    # 窗宽与步长换算成样本；输出窗中心从 t_min+half 以步长滑动到 t_max
    window_width = float(window_seconds) * float(sample_rate)
    hop_width = window_width * float(hop_ratio)
    if window_width <= 0.0 or hop_width <= 0.0:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    half = window_width * 0.5
    t_min = float(np.min(centers))
    t_max = float(np.max(centers))
    out_centers_list: list[float] = []
    center = t_min + half
    while center <= t_max:
        out_centers_list.append(center)
        center += hop_width
    if not out_centers_list:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)
    out_centers = np.asarray(out_centers_list, dtype=np.float64)
    sums = np.empty(out_centers.size, dtype=np.float64)

    # ===================== 3. 逐二级窗平方求和 =====================
    for index, out_center in enumerate(out_centers):
        low = out_center - half
        high = out_center + half
        # 取落在 [low, high) 内的一级特征值并平方求和
        mask = (centers >= low) & (centers < high)
        sums[index] = float(np.sum(values[mask] ** 2))

    # ===================== 4. 返回结果 =====================
    return out_centers, sums
```

## 4. ST PSD sum（扣除本底后短时 PSD 带内求和）

### 中文含义

以信号前 1 s 估计本底噪声 PSD，将每个短时窗的 PSD 减去本底，再在指定频带内**逐点求和**，得到该窗的“超额谱能量”。

### 物理意义

用文件开头作为噪声基准，扣除后只保留**超出本底的部分**，从而去除背景/系统噪声的固定贡献。对相减后的 PSD 在频带内求和，量化该频带内超出本底的功率总量；数值大说明该时刻该频带存在显著信号（撞击、放电等瞬态事件）。输入单位 rad → PSD 单位 rad²/Hz → 输出 rad²/Hz。

### 计算公式

本底（`welch`，Hann 窗，`nperseg = round(PSD Window × fs)`，`noverlap = nperseg//2`，`detrend="linear"`，`scaling="density"`）：

$$
B_k = \text{welch}(x[0: N_{\text{bg}}])[k]
$$

对每个短时窗（相同 `nperseg`，故频率网格与 B 一致）：

$$
\text{out}[j] = \sum_{k \in [\text{Band Low}, \text{Band High}]} \left( \text{PSD}_j[k] - B_k \right)
$$

### 函数定义与实现代码

```python
def compute_short_time_psd_sum(
    values: np.ndarray,                # 输入：一维信号数组（rad），长度 N
    sample_rate: float,                # 采样率（Hz）
    *,
    psd_window_seconds: float,         # 短时/本底 PSD 窗宽（s）
    hop_seconds: float,                # 滑动步长（s），绝对值
    background_seconds: float,         # 本底取信号前多少秒（s）
    band_low_hz: float,                # 频带下限（Hz）
    band_high_hz: float,               # 频带上限（Hz）
) -> tuple[np.ndarray, np.ndarray]:    # 输出：(窗中心样本索引, 带内超额 PSD 求和)
    signal = np.asarray(values, dtype=np.float64)

    # ===================== 1. 输入校验 =====================
    if signal.size < 2 or sample_rate <= 0.0:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)
    if psd_window_seconds <= 0.0 or hop_seconds <= 0.0 or background_seconds <= 0.0:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)
    if band_low_hz < 0.0 or band_high_hz <= 0.0 or band_low_hz >= band_high_hz:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    # ===================== 2. 参数换算（秒 -> 样本） =====================
    nperseg = max(2, int(round(psd_window_seconds * sample_rate)))
    hop = max(1, int(round(hop_seconds * sample_rate)))
    background_samples = max(1, int(round(background_seconds * sample_rate)))

    # ===================== 3. 本底噪声 PSD =====================
    # 用信号前 background_seconds 秒估计本底（线性密度 rad²/Hz）
    background_segment = signal[:background_samples]
    if background_segment.size < nperseg:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    freqs, background_psd = welch(
        background_segment,
        fs=sample_rate,
        window="hann",
        nperseg=nperseg,
        noverlap=nperseg // 2,
        detrend="linear",
        scaling="density",
        return_onesided=True,
    )
    # 频带掩码（与本底 PSD 同网格）
    band_mask = (freqs >= band_low_hz) & (freqs <= band_high_hz)
    if not np.any(band_mask):
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    # ===================== 4. 短时滑窗 PSD =====================
    starts = np.arange(0, signal.size - nperseg + 1, hop, dtype=np.int64)
    if starts.size == 0:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    centers = np.empty(starts.size, dtype=np.float64)
    sums = np.empty(starts.size, dtype=np.float64)
    for index, start in enumerate(starts):
        stop = int(start + nperseg)
        segment = signal[int(start):stop]
        centers[index] = start + (nperseg * 0.5)  # 窗中心样本索引
        if segment.size < nperseg:
            sums[index] = 0.0
            continue
        # --- 每个窗的 PSD（与背景同参数）---
        _, psd = welch(
            segment,
            fs=sample_rate,
            window="hann",
            nperseg=nperseg,
            noverlap=nperseg // 2,
            detrend="linear",
            scaling="density",
            return_onesided=True,
        )
        # --- 扣除本底后，频带内逐点求和 ---
        diff = psd - background_psd
        sums[index] = float(np.sum(diff[band_mask]))

    # ===================== 5. 返回结果 =====================
    return centers, sums
```

## 5. ST-energy-max-num（ST Energy 超阈值子窗计数）

### 中文含义

先计算 `ST Energy` 曲线，再用较宽滑窗（默认 70 ms）将其切成多个 1 ms 子窗，统计“子窗内最大能量 > 阈值（默认 400）”的子窗个数，范围 0~70。

### 物理意义

这是一个**事件计数/占空比型**特征：它不关心能量总量，而关心在 70 ms 内有多少个 1 ms 片段发生了超过阈值的能量脉冲。对“高频能量爆发是否频繁、是否占满整窗”非常敏感，适合刻画周期性瞬态或连续撞击活动；数值 70 表示整窗 70 个 1 ms 子窗全部超过阈值。

### 计算公式

**阶段 1**：同 `ST Energy`，输出曲线 `(y[i], t[i])`。

**阶段 2**：以窗宽 `window_seconds`、步长 `hop_seconds`（绝对值）滑动。每个二级窗被切成 `sub_count = round(window_width / sub_width)` 个互不重叠的子窗（默认 70 ms / 1 ms = 70 个）：

$$
\text{count}[j] = \#\left\{\, k \in [0, \text{sub\_count}) \;\middle|\; \max_{i:\, t[i] \in \text{子窗}_k} y[i] > \text{max\_threshold} \,\right\}
$$

X 坐标为二级窗中心。输出为计数（整数，范围 0 ~ sub_count）。

### 函数定义与实现代码

```python
def compute_short_time_max_num(
    feature_centers: np.ndarray,       # 阶段1 窗中心（样本索引）
    feature_values: np.ndarray,        # 阶段1 特征值
    *,
    window_seconds: float,             # 二级窗宽（s），默认 0.07
    hop_seconds: float,                # 二级步长（s，绝对值），默认 0.015
    sub_window_seconds: float,         # 子窗宽（s），默认 0.001（1 ms）
    max_threshold: float,              # 子窗最大值阈值，默认 400
    sample_rate: float,                # 采样率（Hz），用于把秒换算成样本
) -> tuple[np.ndarray, np.ndarray]:    # 输出：(二级窗中心, 超阈值子窗个数)
    centers = np.asarray(feature_centers, dtype=np.float64)
    values = np.asarray(feature_values, dtype=np.float64)

    # ===================== 1. 输入校验 =====================
    if centers.size == 0 or values.size != centers.size or sample_rate <= 0.0:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)
    if window_seconds <= 0.0 or hop_seconds <= 0.0 or sub_window_seconds <= 0.0:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    # ===================== 2. 二级滑窗网格生成 =====================
    window_width = float(window_seconds) * float(sample_rate)
    hop_width = float(hop_seconds) * float(sample_rate)
    sub_width = float(sub_window_seconds) * float(sample_rate)
    if window_width <= 0.0 or hop_width <= 0.0 or sub_width <= 0.0:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    half = window_width * 0.5
    t_min = float(np.min(centers))
    t_max = float(np.max(centers))
    out_centers_list: list[float] = []
    center = t_min + half
    while center <= t_max:
        out_centers_list.append(center)
        center += hop_width
    if not out_centers_list:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)
    out_centers = np.asarray(out_centers_list, dtype=np.float64)

    # ===================== 3. 子窗划分与超阈值计数 =====================
    # 每个二级窗切成 sub_count 个互不重叠的子窗（默认 70 ms / 1 ms = 70 个）
    sub_count = max(1, int(round(window_width / sub_width)))
    counts = np.empty(out_centers.size, dtype=np.float64)
    for index, out_center in enumerate(out_centers):
        low = out_center - half
        num = 0
        for sub_index in range(sub_count):
            sub_low = low + sub_index * sub_width
            sub_high = sub_low + sub_width
            # 子窗内一级特征最大值超过阈值则计数 +1
            mask = (centers >= sub_low) & (centers < sub_high)
            if np.any(mask) and float(np.max(values[mask])) > max_threshold:
                num += 1
        counts[index] = float(num)

    # ===================== 4. 返回结果 =====================
    return out_centers, counts
```

| --- | --- |
| Band Low / High (Hz) | 4000 / 10000 |
| Stage 1 Window (ms) | 0.1 |
| Stage 1 Step (% of window) | 50 |

| Stage 2 Window (ms) | 70 |

## 6. SVM Prediction（滑窗 SVM 预测）

### 中文含义

用预训练的 sklearn SVM 模型，对每个滑窗提取频带能量/比值/统计特征并输出 0/1 分类预测。

### 物理意义

将人工判读规则转化为模型分类：把每个窗映射为“正常/异常”两类，用于自动标注事件区段。模型与特征清单由 `models/saved_models` 下的 `svm_model.joblib` 与 `svm_model_metadata.json` 决定。

### 计算流程

1. 滑窗默认 `window_seconds = 0.04 s`、`hop_ratio = 0.5`。
2. **门控**：信号经 20 kHz 高通后，窗内峰值 `max(|gate|) ≤ 0.05` 的窗跳过（输出 0）。
3. **特征提取**：对活跃窗计算元数据指定的能量频带能量、能量密度比（参考频带 1000–60000 Hz）与统计频带统计量。
4. **预测**：SVM 模型输出 0/1。

### 函数定义与实现代码

```python
def compute_short_time_svm_predictions(
    values: np.ndarray,                # 输入：一维信号数组（rad），长度 N
    sample_rate: float,                # 采样率（Hz）
    *,
    predictor: SlidingWindowSVMPredictor,  # 已加载的 SVM 模型与特征元数据
    window_seconds: float = 0.04,      # 窗宽（s）
    hop_ratio: float = 0.5,            # 步长 = window_samples × hop_ratio
    gate_highpass_hz: float = 20000.0, # 门控高通截止（Hz）
    gate_peak_threshold: float = 0.05, # 门控峰值阈值
) -> tuple[np.ndarray, np.ndarray]:    # 输出：(窗中心样本索引, 0/1 预测)
    signal = np.asarray(values, dtype=np.float64)

    # ===================== 1. 输入校验与滑窗网格生成 =====================
    if signal.size == 0 or sample_rate <= 0.0:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    window_samples = max(2, int(round(window_seconds * sample_rate)))
    if window_samples > signal.size:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    hop_samples = max(1, int(round(window_samples * hop_ratio)))
    starts = np.arange(0, signal.size - window_samples + 1, hop_samples, dtype=np.int64)
    if starts.size == 0:
        return np.array([], dtype=np.float64), np.array([], dtype=np.float64)

    # 输出数组初值全 0，只有活跃窗会被填充预测值
    centers = starts.astype(np.float64) + (window_samples * 0.5)
    predictions = np.zeros(starts.size, dtype=np.float64)
    chunk_size = _compute_chunk_size(window_samples, len(predictor.selected_features))
    ratio_range = (1000.0, 60000.0)

    # ===================== 2. 门控：筛选活跃窗 =====================
    # 20 kHz 高通后窗内峰值 > 阈值的窗才参与特征提取与预测
    raw_window_view = np.lib.stride_tricks.sliding_window_view(signal, window_samples)[::hop_samples]
    gate_signal = _highpass_filter(signal, sample_rate, gate_highpass_hz)
    gate_window_view = np.lib.stride_tricks.sliding_window_view(gate_signal, window_samples)[::hop_samples]
    gate_peak = np.max(np.abs(gate_window_view), axis=1)
    active_indices = np.flatnonzero(gate_peak > gate_peak_threshold)
    if active_indices.size == 0:
        return centers, predictions

    # ===================== 3. 能量频带特征（分块 FFT） =====================
    active_raw_window_view = raw_window_view[active_indices]
    feature_store = _make_feature_store(active_indices.size, predictor.selected_features)
    raw_freqs = np.fft.rfftfreq(window_samples, d=1.0 / sample_rate)

    for chunk_start, chunk_stop, raw_windows in _iter_window_chunks(active_raw_window_view, chunk_size):
        chunk_slice = slice(chunk_start, chunk_stop)
        raw_spectrum = np.fft.rfft(raw_windows, axis=1)
        raw_power = np.abs(raw_spectrum) ** 2
        _assign_energy_features(
            feature_store,
            chunk_slice,
            raw_power,
            raw_freqs,
            predictor.energy_bands,
            ratio_range,
        )

    # ===================== 4. 统计频带特征（并行） =====================
    max_workers = min(len(predictor.stat_bands), max(1, os.cpu_count() or 1))
    if max_workers <= 1:
        stat_results = [
            _compute_stat_band_feature_block(
                signal,
                sample_rate,
                low_hz,
                high_hz,
                window_samples,
                hop_samples,
                chunk_size,
                predictor.selected_features,
                active_indices,
            )
            for low_hz, high_hz in predictor.stat_bands
        ]
    else:
        with ThreadPoolExecutor(max_workers=max_workers) as executor:
            futures = [
                executor.submit(
                    _compute_stat_band_feature_block,
                    signal,
                    sample_rate,
                    low_hz,
                    high_hz,
                    window_samples,
                    hop_samples,
                    chunk_size,
                    predictor.selected_features,
                    active_indices,
                )
                for low_hz, high_hz in predictor.stat_bands
            ]
            stat_results = [future.result() for future in futures]

    # 汇总统计特征到统一的特征存储
    for _band_label, stat_feature_store in stat_results:
        for feature_name, values in stat_feature_store.items():
            feature_store[feature_name] = values

    # ===================== 5. 模型预测与输出 =====================
    feature_frame = pd.DataFrame(
        {feature_name: feature_store[feature_name] for feature_name in predictor.selected_features}
    )
    predictions[active_indices] = predictor.model.predict(feature_frame).astype(np.float64, copy=False)
    return centers, predictions
```

**说明**：该函数依赖以下内部辅助函数（均定义于 `src/processing.py`）：

| 辅助函数 | 作用 |
| --- | --- |
| `_highpass_filter(signal, fs, cutoff)` | 4 阶 Butterworth 高通（门控信号预处理） |
| `_compute_chunk_size(window_samples, feature_count)` | 按内存预算计算分块大小 |
| `_make_feature_store(window_count, feature_names)` | 初始化特征存储字典（全 0） |
| `_iter_window_chunks(window_view, chunk_size)` | 分块迭代滑窗视图 |
| `_assign_energy_features(...)` | 计算能量频带能量与能量密度比特征 |
| `_assign_stat_features(...)` | 计算统计特征：峭度、过零率、谱质心、峰频、峰幅、谱平坦度 |
| `_compute_stat_band_feature_block(...)` | 对每个统计频带做带通滤波并计算统计特征 |
| `load_sliding_window_svm_predictor(model_directory)` | 从 `models/saved_models` 加载模型与元数据 |
